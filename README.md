# Pure CSS News Portal (KabarTekno)

Proyek ini adalah halaman beranda portal berita sederhana bernama **KabarTekno**. Proyek ini dibangun murni menggunakan **HTML5** dan **CSS3** tanpa bantuan framework UI seperti Bootstrap atau Tailwind CSS. Tujuan dari proyek ini adalah untuk melatih kemampuan menyusun tata letak halaman web yang padat informasi secara mandiri, rapi, dan terstruktur.

## 🎯 Fokus Latihan & Konsep CSS

Dalam pembuatan portal berita ini, fokus utama pembelajaran meliputi:
- **Arsitektur Layout Kompleks:** Membagi struktur halaman menjadi area `header`, `nav` (bar navigasi), `main content` (berita utama & daftar sub-berita), `aside` (sidebar kolom tren), dan `footer`.
- **CSS Box Model & Spacing:** Menerapkan kombinasi properti `margin`, `padding`, dan `gap` secara presisi untuk mengatur ruang antar artikel agar teks nyaman dibaca dan tidak menempel satu sama lain.
- **Sizing Constraints:** Menggunakan batas ukuran `max-width` pada kontainer utama agar halaman web tetap proporsional saat dibuka di layar monitor yang lebar, serta `min-width` untuk menjaga komponen tidak gepeng.
- **Flexbox Layout:** Memanfaatkan `display: flex` dengan `flex-wrap: wrap` untuk pembagian kolom konten utama dan sidebar yang fleksibel.
